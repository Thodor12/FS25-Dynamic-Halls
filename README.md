# Dynamic Halls

A dynamically buildable hall/barn system for Farming Simulator 25. Players
purchase a footprint, design their hall's layout at runtime by placing wall,
floor, and roof pieces on a grid, then finalize the build.

## Project structure

```
FS25_DynamicHalls/   the mod itself - ships as-is, this is what gets zipped/installed
Source/               .blend files and source PNG textures - never shipped with the mod
```

## Installation (players)

Copy the `FS25_DynamicHalls` folder into your FS25 mods directory:
`Documents\My Games\FarmingSimulator2025\mods\`
